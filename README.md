# 1 Общее описание
Приложение реализовано в форме консольного интерфейса (CLI) и повторяет
базовое поведение командной строки UNIX-подобной ОС. Приглашение к вводу
формируется из реальных данных ОС: имени пользователя, имени хоста и
текущей рабочей директории. Поддерживается раскрытие переменных окружения
(`$VAR`, `${VAR}`) и тильды (`~`). Команды `ls` и `cd` на данном этапе
являются заглушками и лишь выводят своё имя и аргументы — это позволяет
отладить парсер и цикл REPL отдельно от низкоуровневой логики.

# 2 Описание всех функций и настроек
## Список реализаций 
Этап 1. REPL:
1. Приложение реализовано в форме консольного интерфейса (CLI).
2. Приглашение к вводу формируется на основе реальных данных ОС
   (`username@hostname:~$`).
3. Парсер поддерживает раскрытие переменных окружения (`$HOME` и др.).
4. Реализованы команды-заглушки `ls` и `cd`, выводящие своё имя и аргументы.
5. Реализована команда `exit`.
6. Продемонстрирована работа прототипа в интерактивном режиме,
   включая обработку ошибок.
7. Результат сохранён в репозитории оформленным коммитом.

Этап 2. Конфигурация:
1. Поддержаны параметры командной строки: `--vfs`, `--prompt`, `--script`.
2. Стартовый скрипт выполняет команды эмулятора последовательно и
   останавливается при первой ошибке.
3. При выполнении скрипта на экране отображается и ввод, и вывод,
   имитируя диалог с пользователем.
4. Ошибка во время исполнения стартового скрипта сообщается пользователю
   вместе с текстом строки, вызвавшей остановку.
5. Созданы скрипты реальной ОС (`scripts/test_vfs.bat`,
   `scripts/test_prompt.bat`, `scripts/test_script.bat`), каждый вызывает
   эмулятор и тестирует поддерживаемые параметры командной строки.
## Список функций 
- `make_prompt(custom_prompt)` — формирует приглашение `username@hostname:~$`
  или возвращает пользовательское приглашение.
- `expand_line(line)` — раскрывает переменные окружения (`$HOME`, `${VAR}`).
- `parse_line(line)` — разбивает строку на токены через `shlex.split`;
  возвращает `None` при незакрытых кавычках.
- `expand_tilde(args)` — раскрывает `~` в аргументах.
- `cmd_ls(args)` — заглушка `ls`, выводит имя и аргументы.
- `cmd_cd(args)` — заглушка `cd`, выводит имя и аргументы.
- `dispatch(line)` — выполняет одну строку ввода, возвращает статус:
  успех, ошибка или команда `exit`.
- `parse_args(argv)` — разбирает параметры командной строки.
- `run_interactive(cfg)` — цикл REPL.
- `read_script(path)` — читает стартовый скрипт, сообщает об ошибке открытия.
- `run_script(cfg)` — выполняет стартовый скрипт до первой ошибки.
- `main(argv)` — точка входа, выбирает режим: скрипт или интерактив.

# 3  Описание команд для сборки проекта и запуска тестов.
- Python 3.8+
- Модули стандартной библиотеки:
- Модули стандартной библиотеки:
  `argparse`, `os`, `sys`, `shlex`, `getpass`, `socket`, `typing`.
- Команда для запуска: `python src/main.py`
- Сценарии проверки:
  1. Запуск приложения: `python src/main.py`.
  2. Раскрытие переменных: ввод `ls $USERNAME`.
  3. Раскрытие тильды: ввод `ls ~`.
  4. Обработка кавычек: ввод `ls one "hello world" three`.
  5. Неизвестная команда: ввод `unknowncmd`.
  6. Незакрытые кавычки: ввод `ls "unclosed`.
  7. Пустой ввод — приглашение повторяется без ошибки.
  8. Команда `exit` завершает работу.
  9. Пользовательское приглашение: `python src/main.py --prompt "TEST> "`.
  10. Параметр VFS: `python src/main.py --vfs data/vfs.json`.
  11. Стартовый скрипт: `python src/main.py --script scripts/script.txt`.
  12. Отсутствующий скрипт: `python src/main.py --script nofile.txt`.
  13. Остановка скрипта на первой ошибке — строка с `unknowncmd` внутри
      скрипта прерывает выполнение.
- Запуск тестов: `python -m pytest tests/`
- Запуск через скрипт сборки: `./run.sh --script scripts/script.txt`
